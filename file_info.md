# Directory File Information

This document explains the purpose of every single file and folder in the `d:\CODE\rajasthani` directory, helping you understand how the machine learning pipeline is structured.

### Why is there both `generate_notebook.py` and `Xgboost.ipynb`?
* **`Xgboost.ipynb`**: This is the actual Jupyter Notebook that you open in VS Code to see visual blocks of code and output. However, underneath the hood, an `.ipynb` file is just a massive, strictly formatted JSON string.
* **`generate_notebook.py`**: AI assistants (like me) cannot safely type raw code directly into an `.ipynb` file without accidentally breaking the strict JSON formatting and corrupting the file. To solve this, I wrote `generate_notebook.py`. It is a "factory script" that holds the notebook code safely, formats it into valid JSON, and then automatically builds and spits out `Xgboost.ipynb`. That is why they contain the same code: the Python script is the blueprint that built the notebook!

## 📁 Folders

* **`DATA/`**
  * Contains all the raw and downloaded CSV data. This includes the `NIFTY50` Indian stock data, the tricky `aux data 1` and `aux data 2`, and the dynamically downloaded `us markets` data (AAPL, MSFT, TSLA).
* **`shitimon/`**
  * Your Python Virtual Environment. This is an isolated "sandbox" where all the installed libraries (like PyTorch, XGBoost, Pandas, and yfinance) live. It ensures they don't interfere with your computer's global Python installation.

## 📄 Core Machine Learning Scripts (Python)

* **`auto_tuner.py`**
  * The original XGBoost training script. It loads the NIFTY 50 `RELIANCE` data, engineers the features (momentum, moving averages), defines the high-accuracy prediction target (volatility spikes), and tunes the XGBoost algorithm on your RTX 3050 GPU to reach >95% accuracy.
* **`test_aux_data.py`**
  * The script designed to test the model's resilience on weird, tricky data. It merges multiple NIFTY files together (handling overlapping times), deals with the fact that index data (`NIFTY AUTO`) doesn't have Volume metrics, and retunes the AI to prove it can still get >95% accuracy on new Indian data.
* **`predict_us_markets.py`**
  * The cross-market testing script. It uses the `yfinance` library to download live historical data for US stocks (Apple, Microsoft, Tesla). It then loads the AI *weights* (the brain) trained on Indian NIFTY data and runs predictions on the US market without retraining, achieving up to 99% zero-shot accuracy.
* **`generate_notebook.py`**
  * The factory script that safely builds and formats the `Xgboost.ipynb` Jupyter Notebook to prevent file corruption.

## 📓 Jupyter Notebooks

* **`Xgboost.ipynb`**
  * The interactive notebook version of the XGBoost pipeline. Generated by `generate_notebook.py`.
* **`pytorch.ipynb`**
  * An older, mostly empty notebook created to test if PyTorch and CUDA were working correctly on your GPU.

## ⚙️ System & Data Files

* **`xgb_weights.json`**
  * The saved "brain" of the AI. When `predict_us_markets.py` or `auto_tuner.py` trains the XGBoost model, it saves the underlying math tree here. This allows us to load the model instantly on other datasets without needing to spend time retraining it.
* **`success.txt`**
  * A tiny text file outputted by `auto_tuner.py` containing a single line confirming that the 95% accuracy threshold was mathematically breached.
* **`.gitignore`**
  * Tells Git which files and folders to ignore when uploading to GitHub (e.g., it ignores the massive `shitimon` virtual environment folder so you don't upload gigabytes of standard Python libraries).
